# Cricket ordinary-chat semantic contract

Review transformations as typed changes instead of a single similarity score.

Material transformations include:
- STRENGTHENED / WEAKENED
- REFERENT_CHANGED
- PREDICATE_CHANGED
- CONTRADICTED
- SCOPE_BROADENED / SCOPE_NARROWED
- AUTHORITY_ESCALATED
- CURRENTNESS_PROMOTED
- PROVENANCE_CHANGED
- AMBIGUITY_COLLAPSED
- ADDED / DROPPED

The central anti-Righter rule is literal proposition preservation. A source proposition such as `PROBABLE(X)` must not silently become `ASSERTED(X)` just because the assistant wants to sound decisive.
